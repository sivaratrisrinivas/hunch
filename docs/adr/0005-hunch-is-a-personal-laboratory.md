# Hunch is a personal laboratory

Hunch exists so one user can watch one transformer learn from that user's command history. Daily use still shows one Suggestion from the Champion. Looking at the distribution, command-ngram, and bits per byte of one Suggestion is Inspection, invoked as `hunch inspect`. Other shells, a landing page, and sampling in Daily use were rejected as product work that hides the mechanism. A public teaching repo is allowed only after Inspection has numbers the user has actually read.
